# Customer Shopping Behavior Analysis

This project analyzes customer shopping behavior using Python, SQL, and Power BI to generate business insights and visualize customer purchasing patterns.

---

## Project Overview

The project focuses on:

- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- SQL Business Queries
- Customer Segmentation
- Revenue and Sales Analysis
- Interactive Power BI Dashboard

---

## Tools & Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- SQL (MySQL)
- Power BI
- Excel

---

## Dataset Features

The dataset includes:

- Customer Demographics
- Product Categories
- Purchase Amount
- Review Ratings
- Discount Usage
- Subscription Status
- Shipping Type
- Purchase Frequency

---

## Key Insights

- Female customers generated higher revenue.
- Customers using discounts showed higher purchase amounts.
- Subscription users contributed more repeat purchases.
- Customers aged 26–40 generated the highest revenue.
- Express shipping users had higher average purchase value.
- Loyal customers contributed significantly to total sales.
